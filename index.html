十月的帕米尔

白沙湖、盘龙古道与喀拉库勒湖

10月14日至16日参加塔县三天两晚行程。白沙湖、塔合曼湿地安排在14日；国门、盘龙古道与托格伦夏村安排在15日；冰川与喀拉库勒湖留给16日返程。具体路线、集合时间与住宿以团方确认为准。

逐日展开

十二天的行程

点开当天查看交通、安排与住宿。时间以已整理的行程信息为准。

09OCT 广州 → 济南抵达后游览大明湖周边 飞行 / 济南

交通12:50 乘山东航空 SC1170 从广州白云 T3 起飞，15:30 抵达济南遥墙机场。

安排前往市区入住，晚间游览大明湖周边和超然楼，在芙蓉街一带用餐。

住宿济南市区，酒店待定。趵突泉或泉城广场一带便于次日游览和前往机场巴士站。

济南机场至市区机场巴士 1 号线约 95 分钟，抵达后按出站时间选择班次或网约车。

10OCT 济南 → 乌鲁木齐趵突泉 / 机场巴士 / 晚间航班 游览 / 飞行

07:00-09:00游览趵突泉。

09:00-10:20回酒店取行李，前往玉泉森信大酒店机场巴士站。建议前一晚确认行李寄存和到站时间。

10:20计划乘机场巴士 1 号线，运行约 95 分钟，预计 11:55 到机场。请按当天班次和路况留足时间。

航班14:30 乘山东航空 SC8709 从济南遥墙起飞，20:40 抵达乌鲁木齐天山。

住宿乌鲁木齐。原计划中的市区游玩调整为抵达、入住和休息。

11OCT 乌鲁木齐 / 天山天池晚上回市区用餐 一日游

安排前往天山天池，约 20:00 返回市区，到大巴扎吃饭。

住宿乌鲁木齐。

洗漱洗头、洗澡、洗衣服。

12OCT 乌鲁木齐 → 喀什市区逛吃 / 夜间火车 夜间交通

安排白天在乌鲁木齐市区逛吃。

交通20:40 乘火车前往喀什，夜宿火车上。车次和站点尚未提供。

13OCT 喀什清晨抵达，喀什游玩一天 喀什

安排早上抵达喀什。若不能提前入住，可找洗浴中心或健身房洗澡，再开始当天游玩。

住宿喀什。

洗漱洗头、洗澡、洗衣服。

14OCT 喀什 → 塔县加入三天两晚行程 / 白沙湖 帕米尔

安排参加塔县三天两晚团，前往塔县，游览白沙湖、塔合曼湿地。

住宿塔县，团内住宿。

洗漱计划不洗澡。

15OCT 塔县周边国门 / 盘龙古道 / 托格伦夏村 帕米尔

安排游览国门、盘龙古道和托格伦夏村。

住宿塔县，团内住宿。

“托格伦夏村”地名待核对。洗漱计划为擦身子。

16OCT 塔县 → 喀什冰川 / 喀拉库勒湖 / 返回喀什 帕米尔

安排游览冰川和喀拉库勒湖，之后返回喀什。

住宿喀什。

洗漱洗头、洗澡、洗衣服。

17OCT 喀什 / 莎车 → 库尔勒莎车一日往返 / 20:30 火车 衔接较紧

安排退房后前往莎车游玩一天，再返回喀什。

交通20:30 乘火车前往库尔勒，夜宿火车上。车次和站点尚未提供。

莎车往返喀什后赶火车的衔接较紧。提前核对交通时间、返程方式和到站时间。

18OCT 库尔勒约 06:00 抵达 / 尝试提前入住 库尔勒

安排约 06:00 抵达库尔勒，尝试酒店提前入住并洗澡，之后游玩一天。

住宿库尔勒。提前入住尚未确认，确认前不视为已预订。

19OCT 塔里木胡杨林早上乘大巴，下午回库尔勒 胡杨秋色

安排早上乘大巴前往塔里木胡杨林，下午返回库尔勒休息。

住宿库尔勒。

出发前确认大巴往返班次和实际游览时间。

20OCT 库尔勒 → 北京 → 广州清晨出发，下午返程 返程

06:00从库尔勒市区出发前往梨城机场。

08:25-12:25南方航空 CZ5603，从库尔勒梨城飞往北京大兴。

14:30-17:40南方航空 CZ3162，从北京大兴飞往广州白云 T2。中转约 2 小时 05 分钟。

确认两段航班是否为联程、行李能否直挂，以及北京大兴中转要求。
